How it works

One topic in, one finished vertical Short out. Each stage is deterministic and leaves an artifact you can inspect.

01

Script

A topic pack or Sensei lesson becomes a tight, segmented script sized for a ~20–30s Short.

02

Voiceover

Text-to-speech narration per segment, with selectable persona and tone presets.

03

Visuals

Per-segment imagery — generated frames or archived Sensei diagrams — composited to 720×1280.

04

Captions

Burned-in captions, including right-to-left Arabic, aligned to the narration.

05

Proof

Every render emits a manifest with SHA-256 hashes for the video, thumbnail, script, and caption.

🔎 What this demo is — and isn't

  • Generated locally. Every clip on this page was rendered on a local machine and reviewed before publishing.
  • No public auto-posting. Media Flow does not post to YouTube, TikTok, or Instagram. There is no channel or upload connected here.
  • No OAuth, no account, no spend. This page has no login, no sign-up, and no payment. It is a static showcase.
  • Verifiable artifacts. Each render ships with a manifest of SHA-256 hashes, so a given video can be tied back to the exact script and caption that produced it.
  • Early pilot. This is a working prototype shown with real outputs — not a launched product, and no usage or revenue is claimed.
