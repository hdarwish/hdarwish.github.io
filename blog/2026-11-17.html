Your OS is now a workflow spy

Windows 11 doesn't just track what you install; it tracks which AI agents you invoke, and it does so via a bitmap, not a log.

windowsprivacytelemetryai-tools

We assumed the privacy boundary of the operating system was the file system and the network stack. We were wrong. The new boundary is the process table.

The distinctionThe distinction is not between 'collecting data' and 'not collecting data.' It is between a passive sensor (the OS observing execution) and an active participant (the OS interpreting intent).

01

The List in the DLL

There is a file on your machine called MissionControlAggregator.dll. Inside it, buried in C++ compiler artifacts, are string literals for codex.exe, claude.exe, copilot.exe, and cursor.exe. They sit next to python.exe, gcc.exe, and code.exe. At first glance, this looks like a compatibility shim. A way for Windows to recognize known applications for taskbar grouping or performance hints. But the code doesn't group. It matches.

The feature guarding these checks is named CLICodingAgentUsage. It subscribes to KernelProcess.AppStateChangeSummary and Win32kTraceLogging.AppInteractivitySummary. These are not high-level application events; they are kernel-level notifications that a process has changed state. The DLL listens to these events, parses the executable name, and runs it against its hardcoded list of agents.

02

The Bitmap, Not the Log

Here is the mechanism that makes this distinct from traditional telemetry. When a match occurs, the component does not write a log entry saying User launched claude.exe at 14:02. It sets a bit. The report emitted is called Segments.SubCohorts. It is a bitmap: twelve bits for broad tool categories, four bits for CLI agents, five bits for desktop agents. If codex.exe ran, the bit for codex is set to 1. If it didn't, it is 0.

This is a metric of presence, not duration. The source events include runtime and focus time, but the aggregator discards those details. It keeps only the boolean fact of observation. This is efficient. It is also remarkably difficult to argue against. There is no prompt text. There is no source code. There is no specific task. There is only the fact that you used the tool.

03

Who Is Watching?

The privacy debate usually focuses on content. What data is collected? The answer here is: very little content. No prompts. No code. But the *who* has changed. Previously, if you used an AI coding agent, your employer (via IT monitoring), your cloud provider (via API logs), or the agent vendor (via their own telemetry) knew you used it. Now, your OS vendor knows. And the OS vendor is the one holding the keys to your identity, your device health, and your system integrity.

This is a shift from monitoring *work* to monitoring *workflow*. The bitmap doesn't care what you are building. It cares that you are building with a specific class of tools. It creates a profile of your development environment that is independent of the project. You are not a 'developer working on Project X.' You are a 'user who invokes Claude and GCC.'

The turn

The turn is this: You thought the operating system was the floor. It is now the ceiling, the walls, and the window. It is the only layer that sees everything, and it has decided to start taking notes.

Analogy It is like a library that doesn't read your books, but records which section you walk into. They don't know what you think. They know you are in the 'Science Fiction' aisle, not the 'History' aisle. Over time, that tells them who you are.

Where it breaks The library analogy breaks because the OS doesn't just track location; it tracks the specific 'book' (executable) you picked up, and it does so for a hardcoded list of 'sensitive' books, implying a classification of which tools are noteworthy.

If you're deciding
When
You are evaluating enterprise security or personal privacy on Windows 11
Prefer
Treat the OS as a telemetry node, not a neutral host. Assume the process list is visible to the vendor.
Avoid
Assuming that because no 'content' is collected, the telemetry is benign. The metadata of tool usage is a behavioral fingerprint.

The bit is set. The window is open. You are being watched, not by your boss, but by the machine itself.
